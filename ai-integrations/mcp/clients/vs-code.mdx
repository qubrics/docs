Use this page to connect Qubrics MCP to your AI client.

## Local stdio

<McpUpgradeSafety />

Install the local package once:

```bash
pip install --upgrade qubrics-mcp==3.0.1
```

Use a mailbox key for Mailbox or Sending:

```bash
export QUBRICS_MBX_KEY=smx_mbx_...
```

Use a root key for Management:

```bash
export QUBRICS_ROOT_KEY=smx_root_...
```

Use an input variable so the key is not stored directly in `.vscode/mcp.json`.

```json
{
  "servers": {
    "qubrics-mailbox": {
      "type": "stdio",
      "command": "qubrics-mcp-mailbox",
      "env": {
        "QUBRICS_API_KEY": "${input:qubrics-mailbox-key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "qubrics-mailbox-key",
      "description": "Qubrics mailbox API key",
      "password": true
    }
  ]
}
```

## Private HTTP

Start a local HTTP MCP server:

```bash
QUBRICS_API_KEY=smx_mbx_... \
QUBRICS_MCP_HTTP_BEARER_TOKEN=local-mcp-token \
qubrics-mcp-mailbox --transport http --host 127.0.0.1 --port 8765
```

Use `http://127.0.0.1:8765/mcp` as the client URL.

```json
{
  "servers": {
    "qubrics-local": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "Authorization": "Bearer ${input:qubrics-mcp-token}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "qubrics-mcp-token",
      "description": "Qubrics local MCP bearer token",
      "password": true
    }
  ]
}
```
