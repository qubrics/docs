Use this page to connect Qubrics MCP to your AI client.

## Hosted OAuth

Use the hosted endpoint when the client supports remote MCP OAuth:

```text
https://mcp.qubrics.com/mcp
```

Add this to your Gemini CLI `settings.json`.

```json
{
  "mcpServers": {
    "qubrics": {
      "httpUrl": "https://mcp.qubrics.com/mcp",
      "trust": false
    }
  }
}
```

Then run `/mcp auth qubrics` inside Gemini CLI.

## Local stdio

<McpUpgradeSafety />

Install the local package once:

```bash
pip install --upgrade qubrics-mcp==3.0.1
```

Use a mailbox key for Mailbox or Sending:

```bash
export QUBRICS_MBX_KEY=smx_mbx_...
```

Use a root key for Management:

```bash
export QUBRICS_ROOT_KEY=smx_root_...
```

Add this to Gemini CLI `settings.json`.

```json
{
  "mcpServers": {
    "qubrics-mailbox": {
      "command": "qubrics-mcp-mailbox",
      "env": {
        "QUBRICS_API_KEY": "$QUBRICS_MBX_KEY"
      },
      "trust": false
    }
  }
}
```

## Private HTTP

Start a local HTTP MCP server:

```bash
QUBRICS_API_KEY=smx_mbx_... \
QUBRICS_MCP_HTTP_BEARER_TOKEN=local-mcp-token \
qubrics-mcp-mailbox --transport http --host 127.0.0.1 --port 8765
```

Use `http://127.0.0.1:8765/mcp` as the client URL.

```json
{
  "mcpServers": {
    "qubrics-local": {
      "httpUrl": "http://127.0.0.1:8765/mcp",
      "headers": {
        "Authorization": "Bearer local-mcp-token"
      },
      "trust": false
    }
  }
}
```
